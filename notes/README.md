## About the numericals ⭐⭐⭐
Every numerical in the problem pages is the **exact problem** from the zip — same data, same sub-questions, same numbering — followed by a full worked answer. The course files give questions but **no answers**, so the answers are worked out here step by step. Where a question cannot be solved without an assumption (risk probabilities, vendor ratings for a new weight, carrying-cost rate), the assumption is written in **bold** before the working, and alternative readings are shown. Do the same in the exam: **state the assumption, show the formula, show the substitution, box the answer, interpret it in one line.**

## Exam-day answer tips ⭐⭐
- **Incoterms case**: rule + named place + "Incoterms® 2020" → clue words → seller/buyer table → exact risk point → insurance → why not the nearest alternative.
- **GA numerical**: always present the **settlement table** (made good − contribution = net) and check that nets sum to zero.
- **Outsourcing/contract case**: identify clause → apply facts → evidence → recommendation with a condition.
- **KPI**: formula → value → compare with target → corrective action → reward or penalty.
- Draw: the E-F-C-D Incoterms ladder, the container imbalance loop, the fishbone, the risk heat-map, the 15-step air freight flow.
