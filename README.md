# IL Prep — International Logistics Notes

A minimal static website for the **International Logistics** end-semester exam (MBA OM, Semester III). It covers the eight announced topics — Outsourcing & contract problems, Incoterms, Containerization & container imbalance, Maritime costing, Air security & cost, Insurance & contract (General Average) problems, Air Transportation, and the KPIs book case — built from the course PPTs, PDFs and problem files. Every numerical from the course files is reproduced **exactly** with a full worked answer: 13 outsourcing/KPI/contract problems, 12 Incoterms cases, 5 container imbalance questions, 8 insurance/General Average numericals, all maritime and air costing examples, and the Vibrant Video and Bob's Custom BBQs cases. It also has rapid revision, an exam Q&A bank, 96 MCQs and a glossary of about 130 terms. There is no build step and there are no dependencies: plain HTML, CSS and JavaScript.

## What's inside
```
index.html            the website (dashboard, sidebar, search palette, self-test, flashcards, quiz)
assets/style.css      styling
assets/app.js         loads and renders the notes
assets/notes.js       all notes bundled into one file (generated by build.py)
assets/marked.min.js  Markdown renderer (marked v12, MIT licence)
notes/*.md            the original Markdown notes (also readable on GitHub)
build.py              re-bundles notes/*.md into assets/notes.js
vercel.json           Vercel settings
```

## Preview on your computer
Double-click `index.html`. It works offline because the notes are bundled in `assets/notes.js`.

## Edit the notes
Edit any file in `notes/`, then run:
```bash
python3 build.py
```
and commit both the `.md` file and `assets/notes.js`.

## Host it on Vercel
1. Go to https://vercel.com/new and sign in with GitHub.
2. Click **Import** next to the `IL_Prep` repository (grant Vercel access to it if asked).
3. Framework preset: **Other**. Leave the build command and output directory empty. The root directory is `./`.
4. Click **Deploy**. You get a link like `https://il-prep.vercel.app`.

GitHub Pages also works: repository **Settings → Pages → Deploy from a branch → main / root**.

## Keyboard shortcuts
`Ctrl/⌘ K` or `/` search · `T` self-test · `F` focus mode · `J`/`K` next/previous page · `B` bookmark · `D` mark done · `?` all shortcuts.
